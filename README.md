# CSM Slatina — Site oficial

Site-ul Clubului Sportiv Municipal Slatina: 10 secții sportive și Clubul Nautic și de Agrement „Plaja Olt".

**Slatina, oraș al performanței!** · Construim campioni. Inspirăm generații.

## Structură
- `index.html` — pagina principală (hero parallax, secții, despre, Plaja Olt, FAQ, parteneri)
- `sectii/` — paginile celor 10 secții sportive
- `plaja-olt.html` — Clubul Nautic și de Agrement „Plaja Olt"
- `contact.html` — date de contact

## Tehnologii
HTML/CSS/JS static, animații GSAP + ScrollTrigger, fonturi Google (Poppins & Manrope). Fără build — se poate servi direct (GitHub Pages).
