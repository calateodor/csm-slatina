Panoul site-ului

Intră cu utilizatorul și parola panoului.

Prima configurare — o singură dată: lipește token-ul GitHub și alege-ți utilizatorul și parola cu care vei intra de-acum înainte, de pe orice browser.

Token-ul se salvează criptat cu parola ta — fără parolă, nimeni nu-l poate folosi. O parolă scurtă gen „admin1234" poate fi spartă prin încercări repetate; alege ceva mai lung, de pildă trei cuvinte.

Cum îmi fac token-ul?
  1. Intră pe github.com → Settings → Fine-grained tokens, logat cu contul care deține site-ul.
  2. Nume: „Panou CSM". Expiration: 1 an. Repository access: „Only select repositories" → csm-slatina.
  3. La Permissions → Repository → Contents alege Read and write. Restul rămân neatinse.
  4. Generate token, copiază-l (începe cu github_pat_) și lipește-l aici.

Editare direct în pagină

Pornești modul de editare, deschizi orice pagină a site-ului, și primești: creion ✏️ pe toate textele (titluri, paragrafe, liste, tarife), 🖼️ pe fiecare fotografie (încarci de pe calculator sau lipești un link), 🎬 pe fundalurile speciale (clipul piscinei, scenele de la nautic), iar pe paginile de fotbal și handbal — creion pe cardul deschis din evantai și butonul „👥 Lotul" pentru adăugat/scos jucători. Ce salvezi se publică pe site.
